# Retrieve inspection artifacts

Import reports, typed geometry IDs, four-view images, jobs and artifact retrieval
are available by default through the CLI and local MCP. No opt-in is required. The old CLI `--experimental-inspect` flag and MCP
`experimental_inspect` boolean are accepted as ignored compatibility inputs.
Retained retry keys replay their original inspection settings; use a new key
for an intentional import with different report/image options.

An inspection path names a file on the AgentCAD server. A calling agent can
retrieve its bytes through the existing `inspect` tool without opening that
path on its own machine. No storage service or database is required.

Start with the complete geometry inventory:

```sh
agentcad inspect /server/project/v1_import/output.step --artifact manifest
```

The equivalent MCP call is:

```json
{"file":"/server/project/v1_import/output.step","cwd":"/server/project","artifact":"manifest"}
```

Pass `build_dir` / `--build-dir` when the original response uses a separate
artifact root. The default report includes
`inspection.inventory.retrieve: {"artifact":"manifest"}`: pass that argument
to `inspect` with the same baseline, server `cwd` and build root. CLI callers
add `--artifact manifest` to their existing `inspect FILE` invocation.

The result has the baseline hash, manifest ID and version, plus an `artifact`:

```json
{
  "reference": "/server/project/v1_import/geometry_manifest.json",
  "sha256": "<SHA-256 of the entire file>",
  "total_bytes": 24000,
  "mime_type": "application/json",
  "encoding": "base64",
  "offset": 0,
  "returned_bytes": 3072,
  "data": "<base64 of this chunk>",
  "complete": false,
  "retention": {"state": "durable"}
}
```

When `complete` is false, copy `next.cli` or call `next.mcp.tool` with
`next.mcp.arguments`. These actions include the absolute server-side paths,
original build root, next byte offset and required full-file SHA-256. They work
from another caller directory. When complete, `next` is null.
For retained cache files they also pin `artifact_expires_at`; even identical
regenerated bytes cannot extend the original transfer's expiry.

Decode each chunk with base64, append bytes in offset order, and check the
assembled length and SHA-256 before publishing a local file. JSON and UTF-8
characters can span chunks: decode JSON only after reconstruction. Keep an
incomplete download in a temporary file. A failed continuation does not make
the earlier chunks a complete artifact.

Supported references:

| Reference | Saved bytes |
| --- | --- |
| `manifest` | Complete durable `geometry_manifest.json`, including every part, occurrence, solid, face and edge record |
| `baseline` | Original normalized edit baseline named by `file` |
| `inspection.inventory.report` path | Complete saved analysis, including the full part list and sample plan |
| `inspection.inventory.bundle` path | Saved sample catalogue and omitted-image reasons |
| A saved image PNG or metadata path | Exact rendered pixels or camera/label evidence |

For media with a filename relative to `inventory.image_root`, pass that
filename directly, or the full path under that root. This is a file transfer;
to **see** an image, use the existing MCP `inspect(image=True, entity_id=...)`
attachment. Use `isolate=True` for the isolated target. An unsampled image must
first be requested with `--id ID --image`; artifact retrieval never renders it.

The saved analysis contains all parts; the geometry manifest contains the full
topology inventory. A complete saved response snapshot may already contain a
shortened prepared part list. Retrieve it with the existing
`response_snapshot` parameter and `report=True`; it is not a raw artifact path.

The default chunk is 3,072 raw bytes. `--artifact-bytes` / MCP `artifact_bytes`
accepts 1–49,152 bytes for clients that want fewer calls. Base64 adds about one
third to the byte count, in addition to response metadata. These are explicit
saved-byte reads, outside the import/report token budget. File hashes are
streamed; JSON evidence validation has a 32 MiB per-file limit. A large baseline
is hashed on each read to reject changed geometry, so use larger chunks for bulk
transfer when the client can accommodate them.

Continuation offsets must include `--artifact-sha256` / `artifact_sha256` from
the first response. A hash can also pin the first request when already known,
for example an image's reported SHA-256. A mismatch returns
`inspection_artifact_unavailable` with no data. Arbitrary project files, source
scripts, traversal paths, links, and another baseline's artifacts are rejected.
Do not combine artifact controls with geometry, report, image or job controls.
For retained-artifact continuations, also pass the original
`--artifact-expires-at` / `artifact_expires_at` from the generated action. If
protected job evidence becomes evictable during a transfer, start a new read to
capture its expiry. Durable baseline/manifest reads have no expiry parameter.

Baseline geometry and its manifest are durable. Reports, catalogues and images
retain the existing [inspection cache policy](inspection-cache.md): a read is
protected from concurrent cleanup, but an idle continuation does not pin files
or extend their lifetime. Expired, evicted, corrupt or changed evidence returns
an explicit error. Request a fresh report/image for new evidence; retrieval
never regenerates an old reference or repeats CAD work.

This works over a tool connection to the process running AgentCAD, including
stdio forwarded to another machine. It does not add a hosted MCP endpoint or
extend the separate `cloud_*` HTTPS service. Its deployed inspection API still
has its own capabilities. The full cloud/remote capability matrix remains
separate release work.

## Older face-normal measurements

New ID manifests declare `inventory_revision: 2`; face normals include the full
placed assembly rotation. Earlier manifests retain their original measurements
and ID mapping. Live face lookups qualify those older normals with
`normal_coordinate_frame: surface_local`; their bounding boxes and centroids
remain in assembly coordinates. Reimport into a new version for corrected
assembly-frame normal measurements. Existing manifests and saved responses are
never rewritten during lookup or recovery.
